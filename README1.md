# Sprint 1 – Voetbalmanager

## Sprintperiode

* **Startdatum:** 21-09-2026
* **Einddatum:** 24-09-2026

## Doel van deze sprint

Het doel van deze sprint is om de basis van de voetbalmanager op te zetten. Aan het einde van de sprint moet er een werkende Flask-applicatie zijn waarin clubs en spelers kunnen worden weergegeven.

## Doelstellingen

Tijdens deze sprint ga ik:

* [ ] De GitHub repository opzetten en koppelen aan mijn lokale repository.
* [ ] De basisstructuur van het project maken.
* [ ] Een werkende Flask-applicatie maken.
* [ ] Een basis homepage maken.
* [ ] Een dashboard ontwerpen.
* [ ] Een database opzetten.
* [ ] Clubs toevoegen aan de database.
* [ ] Spelers toevoegen aan de database.
* [ ] Informatie van clubs en spelers kunnen weergeven.
* [ ] Een basis responsive ontwerp maken voor computer en mobiel.
* [ ] Mijn voortgang regelmatig committen en pushen naar GitHub.

## Verwacht resultaat

Aan het einde van Sprint 1 wil ik een werkende basisversie van de voetbalmanager hebben.

De gebruiker moet een club kunnen bekijken en informatie over de spelers van die club kunnen zien. De basis van de website moet werken op zowel computer als mobiel.

## Werkprocessen

In deze sprint oefen ik vooral met:

* **B1-K1-W1:** Stemt opdracht af, plant werkzaamheden en bewaakt de voortgang.
* **B1-K1-W2:** Maakt een technisch ontwerp voor software.
* **B1-K1-W3:** Realiseert (onderdelen van) software.
* **B1-K1-W4:** Test software.
