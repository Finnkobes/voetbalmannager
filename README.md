### Beschrijving van het project

Voor dit project ga ik een eigen voetbalmanagementgame maken voor computer en mobiel. De speler neemt de rol van voetbalmanager aan en krijgt de leiding over een voetbalclub.

De speler kan onder andere spelers bekijken, een opstelling maken, tactieken instellen, spelers kopen en verkopen, trainen en wedstrijden spelen. Wedstrijden worden door het programma gesimuleerd op basis van onder andere de spelers en de gekozen tactiek.

Het doel is om een werkende en overzichtelijke voetbalmanager te maken met een moderne en gebruiksvriendelijke interface.

### Waarom ik dit project wil maken

Ik wil dit project maken omdat ik voetbal leuk vind en het interessant vind om een game te maken waarin je zelf een voetbalclub kunt beheren.

Ook is dit een groter project dan mijn eerdere opdrachten. Hierdoor kan ik veel nieuwe dingen leren en mijn programmeervaardigheden verbeteren. Ik wil uiteindelijk een project hebben dat er professioneel uitziet en waar ik trots op kan zijn.
