# RETRO1 – Voetbalmanager

## Sprintperiode

* Startdatum: 21-09-2026
* Einddatum: 28-09-2026

## Is het gelukt om het product te maken zoals je bedoelde?

Ja, de basis van de voetbalmanager is gelukt. Ik heb een werkende Flask-applicatie gemaakt waarin je een club kunt kiezen en informatie over de club en spelers kunt bekijken.

Er is een database gemaakt met clubs en spelers. Ook heb ik verschillende pagina's gemaakt, zoals het dashboard, de selectie, statistieken, transfers en de opstelling.

## Wat ging goed?

* De Flask-applicatie werkt.
* De database met clubs en spelers werkt.
* Clubs kunnen worden gekozen.
* Spelers worden vanuit de database weergegeven.
* Spelers kunnen worden gefilterd en gesorteerd.
* Salaris en contractduur worden weergegeven.
* De verschillende pagina's zijn met elkaar verbonden.
* De website heeft een basis voor mobiel gebruik.


## Wat ging minder goed?

Tijdens het maken van de website waren er soms problemen met de indeling van de pagina's. Vooral de CSS van de spelerskaarten moest meerdere keren worden aangepast.

Ook kostte het koppelen van de database aan Flask soms meer tijd dan verwacht.

## Wat vond ik lastig?

Ik vond het lastig om ervoor te zorgen dat de gegevens uit de database op de juiste manier op de verschillende pagina's werden weergegeven.

Daarnaast vond ik het soms lastig om de CSS goed te krijgen voor verschillende schermformaten.

## Hoe heb ik dit opgelost?

Ik heb de applicatie steeds opnieuw getest en de code stap voor stap aangepast. Bij problemen heb ik gekeken welke code de fout veroorzaakte en deze vervolgens verbeterd.

Ook heb ik regelmatig gecontroleerd of de database de juiste gegevens bevatte.

## Wat heb ik geleerd?

Deze sprint heb ik geleerd hoe ik:

* Een SQLite database kan gebruiken met Flask.
* Gegevens uit een database kan ophalen.
* Gegevens met Jinja in HTML kan weergeven.
* Flask-routes kan maken.
* Spelers kan filteren en sorteren.
* Een groter project overzichtelijk kan opbouwen.


## Conclusie

Sprint 1 is goed verlopen. De belangrijkste basis van de voetbalmanager is gemaakt en de applicatie werkt. Ik heb tijdens deze sprint vooral geleerd hoe ik Flask, SQLite, HTML, CSS en Git met elkaar kan combineren in één groter project.
